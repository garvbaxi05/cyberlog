# Cyber Permission App

## Overview
Cyber Permission App is a Flutter-based Android application that demonstrates the implementation of multiple permission-based features in a single app. The project focuses on camera access, internet connectivity checking, and device storage access.

This app is intended for learning and academic purposes and is not designed for Play Store deployment.

---

## Features

### Camera Permission
- Requests camera permission at runtime.
- Opens the device camera to capture an image.
- Displays the captured image inside the application.

### Internet Permission
- Checks real internet connectivity using a network lookup.
- Displays the current internet status in the user interface.

### Storage Permission
- Requests full storage access permission.
- Reads the device’s internal storage directory.
- Displays files and folders from phone storage inside the app.

---

## Permissions Used

The following Android permissions are used:

- CAMERA  
- INTERNET  
- MANAGE_EXTERNAL_STORAGE  

These permissions are requested explicitly and are used only for demonstration and learning purposes.

---

## How It Works

1. The app launches and checks the current internet connection.
2. The Open Camera button requests camera permission and allows the user to capture an image.
3. The Check Internet button rechecks internet connectivity and updates the status.
4. The Open Storage button requests storage permission and displays device storage contents.

---

## Purpose

This project is designed to help understand:
- Runtime permission handling in Android
- Camera integration in Flutter
- Internet connectivity verification
- Storage access and file listing
