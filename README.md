# CyberLog

CyberLog is a Flutter application that demonstrates native Android–Flutter communication using MethodChannel and presents device system information in a cyber-style HUD interface.

## Features
- Native Android integration using MethodChannel
- Cyber dark HUD UI
- Displays:
  - Device manufacturer, brand, and model
  - Android version and SDK level

## Project Structure
- `lib/main.dart` – Flutter UI and MethodChannel calls
- `android/app/src/main/kotlin/.../MainActivity.kt` – Native Android system APIs
